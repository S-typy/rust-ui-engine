# Галерея компонентов

```powershell
cargo run -p controls-gallery -- --rows 100000
```

Галерея показывает Ribbon, базовые controls и виртуальную таблицу книг.
Это демонстрационное приложение; данные книг формируются локально.
`--state-file PATH` задаёт файл сохранения ширины, порядка и закрепления колонок.

## Общая toggle-команда

Команда `favorite` зарегистрирована через `register_toggle` с начальным значением
false. «Избранное» доступно в главной ленте, третьим элементом панели быстрого
доступа, на странице «Компоненты» и в меню. Эти представления используют одно
состояние команды. При уменьшении окна оно сохраняется в меню QAT, свёрнутой
группе и общем overflow ленты. F10, затем 3 активирует третью команду QAT.

Pointer, клавиатура и accessibility проходят через общую активацию: доступная
команда меняет checked один раз и выдаёт одно invocation с новым значением.
Отключённая команда не меняет состояние. AccessKit представляет toggle-кнопку
как Button с Toggled; отсутствие checked state снимает этот признак у всех
связанных кнопок. Это программная проекция accessibility, а не заявление о
проверке с конкретным screen reader.

Команда `pin` отражает закрепление колонки, на которой находится фокус таблицы.
Она применяет переданное `invocation.checked`. Если открытый редактор запрещает
операцию, состояние команды восстанавливается из текущей колонки.

## Диагностика и небольшие окна

```powershell
cargo run -p controls-gallery -- --diagnostics --allow-small-window
```

`--diagnostics` выводит после изменений компоновки строки `command-state `,
за которыми следует один JSON object. Поля: `sequence` — число обработанных
активаций favorite, `checked` — текущее состояние, `theme`, `viewport`,
`placements` — видимые представления favorite, `popup_open`, `popup_bounds`,
`items` — видимые пункты меню, `ribbon` — full/collapsed/overflow групп,
`controls` — видимые кнопки, вкладки и пункты меню. Элементы содержат command,
label, role, checked, enabled, bounds и clip в logical pixels. Полностью
обрезанные элементы исключены; повторяющиеся snapshots не выводятся.
Текст пользовательского ввода эта диагностика не журналирует.

`--allow-small-window` отдельно отключает обычный минимум окна 480×320 для
проверки адаптивной ленты. Сам по себе `--diagnostics` размеры не меняет.

Windows-проверка команд использует posted input только в своё дочернее окно,
сохраняет JSON-отчёт и захваты client area:

```powershell
python tests/windows_ribbon_commands_smoke.py --exe target/release/controls-gallery.exe --output-dir target/ribbon-commands-dx12
```

Она проверяет главную ленту, QAT, числовой KeyTip, оба вида overflow,
свёрнутую группу и сохранение состояния при смене темы. Это ограниченная
проверка Ribbon alpha; вложенные popup-меню, нативный IME и screen reader
этим сценарием не проверяются.
