# Диаграммы и Sparkline

`Controls::chart` отображает неизменяемый `ChartModel` через общую Scene. Поддержаны
Cartesian Line, Scatter, Bar и компактный Sparkline. Источник остаётся read-only;
выбор точки является отдельным состоянием представления.

```rust,ignore
let model = ChartModel::new(series, ChartSettings::default())?;
let chart = ui.chart(parent, model, style)?;
let mut next = ui.chart_model(chart).unwrap().clone();
next.replace(updated_series, next.settings().clone())?;
ui.set_chart_model(chart, next)?;
```

`ChartSeries::from_table` читает уже принятую `DataTable` с числовыми X/Y. Ключи
исходных строк сохраняются, NULL в Y разрывает линию и не становится нулём.
Числовые диапазоны, группировка столбцов и hit-test принадлежат одной геометрии;
представление использует её для рисования, выбора и обхода клавиатурой.
[Контракт данных и геометрии](chart-model.md) описывает ограничения преобразований.

## Ввод и обновления

Нажатие и отпускание мыши на одной точке выбирают её. Пустая область снимает выбор.
Перекрывающая кнопка, меню или flyout получает ввод по общему hit-test. Escape,
потеря native capture/фокуса, отключение владельца и успешная внешняя замена модели
отменяют незавершённый жест. Отклонённая замена сохраняет и модель, и текущий жест.

Left/Up и Right/Down обходят видимые ненулевые точки в порядке рядов; Home/End
переходят к первой/последней, Escape снимает выбор. Ctrl/Alt/Win сочетания остаются
общему обработчику команд. Выбор меняется только после проверки существования ключа.
`set_chart_selected` меняет выбор программно без пользовательского события.
`take_chart_selection_changes` возвращает последнее изменение каждого контрола:
несколько действий до чтения объединяются, `previous` сохраняет исходный выбор.
Обновление модели очищает ожидающее событие и старый pointer-жест.

`ChartModel::replace` сохраняет выбранную пару `(series, point)`, если её ненулевое
значение осталось. `set_chart_model` публикует полностью проверенную модель вместе
с её выбором; ошибка геометрии или shaping не меняет принятое представление.

## Отображение и доступность

Обычная диаграмма показывает шкалы, подписи осей, легенду и выбранное значение.
В Light/Dark используются собственные контрастные цвета рядов; фокус и выбранная
точка имеют отдельную рамку. Длинные подписи получают явное многоточие, исходные
имена и числовые значения остаются в модели. Переносы строки в подписях не допускаются.
Числа на шкалах округляются до трёх знаков или выводятся в scientific notation;
хранимые `f64` при этом не изменяются.

Минимальная ширина полного представления — 520 logical px. Высота зависит от легенды:
240 px плюс 26 px на каждую строку четырёх её элементов. При меньшем размере
`chart_display_status` возвращает `Compact`: вместо обрезанных шкал показывается
краткое текстовое состояние. Sparkline не выводит оси/легенду и требует 32×24 px.
Подписи, данные и конечные составные строки проверяются до публикации.

Доступный узел допускает Focus; его read-only описание содержит ряд и координаты
выбранной точки. Прикреплённое описание Badge сохраняется. Отдельное дерево всех
тысяч точек не создаётся, selection API не предоставляет запись в данные.
Обычные клавиши приложения последовательно обходят видимые точки.

В текущем Windows представлении сведения о выбранном ряде и X/Y доступны через
UI Automation FullDescription, но Narrator не произносит эти числовые значения
при чтении диаграммы или запросе дополнительного описания. Проверено произнесение
имён основной диаграммы, компактного графика и кнопки переключения вида;
это не обеспечивает доступное чтение выбранных данных. Обход точек стрелками
при активном Narrator также не подтверждён. Наличие semantic description и
работа обычной клавиатуры приложения не означают полноценную поддержку
экранного диктора для диаграмм.

## Границы

До 16 рядов и 4096 точек суммарно; конечные `f64`, линейные шкалы и ограниченный
viewport. Нет zoom/pan, временных/logarithmic шкал, пользовательских point labels,
анимации, stacked/area, Pie, Heatmap, TreeMap, Sunburst, Sankey и экспорта. Эти виды
не считаются реализованными данным Cartesian срезом.

`xaml-form --charts` использует compiled `ChartsWindow.xaml` и Rust композицию
основной диаграммы с отдельным Sparkline. Кнопки переключают семейства, меняют
диапазон и обновляют типизированную таблицу с сохранением ключей. Отдельный XAML
элемент Chart в этом профиле не требуется.
