# Дата, время и календарь

`DateEdit`, `TimeEdit`, `DateTimeEdit` и `DateRangeEdit` разделяют редактируемый
текст и принятое типизированное значение. `Calendar` предоставляет отдельный
выбор даты или включительного диапазона без текстового редактора.

## Значения и границы

| Rust | Содержание | `Value` binding |
|---|---|---|
| `DateValue` | Григорианская дата, годы 1–9999 | ISO-строка `YYYY-MM-DD` либо `Null` |
| `TimeValue` | Время суток с точностью до секунды | `HH:mm:ss` либо `Null` |
| `DateTimeValue` | Дата и время без часового пояса | `YYYY-MM-DDTHH:MM:SS` либо `Null` |
| `DateRangeValue` | Полная упорядоченная пара `start <= end` | Объект с ISO-строками `start`, `end` либо `Null` |

Время не содержит смещения, часового пояса, дробных секунд или правил перехода
на летнее время. Проверка дат учитывает високосные годы и границы столетий.
`DateValue::checked_add_months` сохраняет день, ограничивая его длиной нового
месяца; `checked_add_days` и `DateTimeValue::checked_add_seconds` возвращают
`None` при выходе за поддерживаемый диапазон.

`Minimum` и `Maximum` включительны. `AllowEmpty` по умолчанию равен `true`.
Для диапазона пустым может быть только всё значение; отдельный конец не может
отсутствовать в принятом `DateRangeValue`. Ошибочные настройки и значения
отклоняются до изменения принятого значения. Изменить формат отображения при
незавершённом редактировании или активной композиции нельзя: сначала требуется
подтвердить либо отменить черновик.

## Отображение и ввод

Русские форматы по умолчанию — `dd.MM.yyyy` и `HH:mm`; формат хранения от них
не зависит. Альтернативный формат даты — `yyyy-MM-dd`. `ShowSeconds` включает
отображение секунд. Скрытые секунды сохраняются при повторном подтверждении,
смене формата и изменении только даты. Ввод другой минуты без секунд задаёт
секунды `00`; явный ввод `HH:mm:ss` задаёт все три части. `TimeStep` от 1 до
86400 секунд применяется к стрелкам и встроенным кнопкам. Шаг `DateTimeEdit`
может переходить через полночь; `TimeEdit` ограничивается текущими сутками.

Enter подтверждает корректный текст. Escape возвращает последнее принятое
значение. По умолчанию уход фокуса подтверждает корректный ввод; ошибка не
удерживает фокус. Незаконченная пара дат остаётся черновиком и не попадает
в модель. У редакторов `Value` binding по умолчанию использует
`TwoWay/LostFocus`; `TextChanged` отдельно сообщает изменение текста.

```xml
<DateTimeEdit Value="{Binding Meeting}"
              Minimum="2026-01-01T00:00:00"
              DateFormat="dd.MM.yyyy" ShowSeconds="True" TimeStep="30" />
<DateRangeEdit Value="{Binding Vacation}"
               Minimum="2026-01-01" Maximum="2026-12-31" />
<TimeEdit Value="{Binding StartTime}" Format="HH:mm" TimeStep="60" />
```

Для статического диапазона XAML использует `Value="2026-10-01/2026-10-07"`.
Binding использует объект `{"start":"2026-10-01","end":"2026-10-07"}`.
Динамические изменения настроек формата и границ учитываются уже установленными
привязками. Источники `ElementName` проверяют тип и границы перед принятием
значения целевым редактором.

## Календарь

```xml
<Calendar Value="{Binding SelectedDates}" SelectionMode="Range"
          DisplayDate="2026-10-01" View="Days"
          Minimum="2026-01-01" Maximum="2026-12-31" />
```

`SelectionMode` фиксируется при создании: `Single` либо `Range`. В диапазоне
первый выбор задаёт начальную точку черновика, второй принимает упорядоченную
пару. `calendar_selection` до второго выбора возвращает прежнее принятое
значение; `calendar_range_anchor` позволяет наблюдать незавершённый выбор.
`CalendarValidator` проверяет полную пару перед изменением выбора. Свойство
`Value` использует `TwoWay/PropertyChanged`.

Заголовок переключает представления `Days`, `Months`, `Years`. Стрелки меняют
страницу, а выбор месяца или года возвращает к более подробному представлению.
Недоступные даты и страницы исключены из выбора. В клавиатурной навигации
стрелки перемещают курсор, PageUp/PageDown меняют страницу, Home/End выбирают
границу текущего периода, Ctrl+Up поднимает уровень, Enter/Space выбирает
элемент. Escape отменяет первую точку самостоятельного диапазона.

`DisplayDate` меняет показываемую дату без изменения выбора. `IsReadOnly`
сохраняет просмотр страниц и запрещает выбор. В дереве доступности календарь
является группой, даты имеют полные названия, выбранные элементы — состояние
выбора. Один элемент сетки участвует в последовательном обходе Tab.

Календарь сохраняет 42 ячейки при переключении представлений. По умолчанию он
занимает 320×300 логических пикселей. Сетка распределяет доступное место;
приложение должно предоставлять достаточную площадь для чтения подписей.
Одновременно поддерживается до 256 экземпляров в одном `Controls`.

## Календарь внутри редактора

`DateEdit` подтверждает выбранную дату сразу; неверное значение оставляет
календарь открытым с ошибкой редактора. Его календарь поддерживает те же
представления дней, месяцев и лет.

`DateTimeEdit` и `DateRangeEdit` используют постоянную всплывающую область.
Выбор в ней меняет черновик; «Применить» или Ctrl+Enter принимает корректное
значение. Escape возвращает принятое значение и закрывает область. Переход
между элементами календаря и кнопками не подтверждает черновик. Закрытие
снаружи следует `CommitOnLostFocus`. Асинхронная проверка оставляет область
открытой до результата; отключение редактора или потеря фокуса окна не
принимает запоздавший результат.

Выбор даты в объединённом редакторе сохраняет время. Если выбранная дата
вместе с прежним временем нарушает точную границу, подтверждение отклоняется:
время необходимо исправить вручную. Закрытие и повторное открытие сохраняет
идентификаторы календаря и кнопок. Удалять требуется весь редактор, а не его
обязательные внутренние части.

Rust API: `date_time_edit`, `date_range_edit`, `calendar`, соответствующие
`*_value`, `set_*_value` и `set_*_settings`; для постоянной области доступны
`temporal_calendar`, `temporal_popup_is_open`, `apply_temporal_popup`,
`cancel_temporal_popup` и `close_temporal_popup`. Открытие использует
`open_editor_popup` или доступные действия Expand/Collapse.

Проверки включают календарные границы, переходы через полночь, сохранение
секунд, атомарную валидацию, bindings, клавиатурные события, геометрию сетки,
доступность и lifecycle асинхронного подтверждения. Синтетические события
не заменяют проверку системного ввода и экранного диктора в окне приложения.
