# M0: изменения GPU-прототипа

Дата: 2026-10-09. Документ описывает изменения реализации; фактические результаты
сборки и GPU-запусков фиксируются отдельно в отчёте проверок.

## Сборка и зависимости

- Сохранён workspace из трёх пакетов: `ui-core`, `ui-render-wgpu`, `gpu-shell`.
  Rust 1.96.0 закреплён в toolchain; `Cargo.lock` фиксирует зависимости.
- `wgpu 30.0.1` и `winit 0.30.13` сохранены. Feature flags ограничены нативными
  GPU backend D3D12/Metal/Vulkan, WGSL и оконными X11/Wayland/Win32/macOS.
- Отключены стандартные Adwaita decorations. Собственная клиентская рамка
  Wayland остаётся отдельной задачей; в compositor без server-side decorations
  окно может отображаться без рамки.
- CI собирает workspace на Ubuntu 24.04, Windows Server 2025 и macOS 15.
  Выполняются fmt, clippy с запретом warnings, unit/doc tests, release build и
  rustdoc. Cargo использует `--locked`; workflow не открывает GPU-окно.

## Разделение ответственности

- `DemoState` и построение демонстрационного интерфейса перенесены из ядра в
  `examples/gpu-shell/src/demo.rs`. `ui-core` содержит геометрию, цвета и Scene
  без зависимости от GPU, оконной платформы или модели демонстрации.
- Сцена передаётся renderer в логических координатах. Прямоугольники по-прежнему
  выводятся через GPU instancing и WGSL.
- [ADR-001](adr/ADR-001-retained-tree.md) фиксирует generational `WidgetId`,
  arena и retained runtime как направление M1.
  [ADR-002](adr/ADR-002-scene-wgpu.md) фиксирует действующую границу Scene/backend.

## GPU и окно

- Renderer возвращает типизированную ошибку и различает показанный кадр,
  временный пропуск и необходимость восстановления surface/device.
- Настройка surface откладывается до кадра с ненулевым размером. Проверяются
  ограничения размера, scale factor и ёмкость batch. Suboptimal frame не
  вызывает перенастройку surface, пока полученная texture ещё используется.
- Shell обрабатывает ошибки создания окна и event loop, ограничивает повторные
  попытки восстановления GPU и сохраняет состояние демонстрации при пересоздании
  renderer. Закрытие окна и Escape завершают цикл событий.
- Диагностика содержит adapter/backend. `WGPU_BACKEND` позволяет проверить
  конкретный включённый backend; software CPU и Noop adapters отвергаются.
- Перед present выполняется уведомление оконной платформы, необходимое для
  корректной интеграции кадров Wayland.

## Оставшиеся ограничения

Это сцена прямоугольников с демонстрационным выбором и прокруткой. Число 100 000
обозначает диапазон индексов, а не готовый TreeGrid или измеренную производительность.
Retained tree, focus, маршрутизация событий, layout adapter, текст, IME,
accessibility, Ribbon и TreeGrid ещё не реализованы. Vello не подключён.

Один batch ограничен 16 384 прямоугольниками. Поддержки clips, transforms,
изображений и glyph atlas пока нет. Unit-тесты и межплатформенная сборка не
заменяют runtime-проверку на реальных GPU; аппаратную потерю device необходимо
проверять отдельным сценарием.
