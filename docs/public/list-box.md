# ListBox: выбор и представление элементов

`ListBox` показывает коллекцию с устойчивыми строковыми ключами. `SelectionSettings`
задаёт одиночный или множественный выбор и режим чтения. Перестановка элементов
сохраняет выбранные ключи; удаление ключа удаляет его из выбора. `ItemsSource`
и `SelectedValue` / `SelectedValues` связываются с наблюдаемой моделью.

## Представление выбора

`set_list_item_presentation` задаёт один из трёх вариантов:

| Вариант | Режим выбора | Действие |
|---|---|---|
| `Plain` | Single или Multiple | Обычный выбор, Ctrl и Shift расширяют множественный выбор |
| `CheckBox` | Multiple | Клик, Space или Enter переключают пункт без Ctrl; стрелки перемещают курсор |
| `RadioButton` | Single | Клик и клавиатурная навигация выбирают один пункт |

Повтор удерживаемого Space/Enter не переключает флажок несколько раз.
Home/End и PageUp/PageDown работают по фактическим высотам строк; ввод первых
символов ищет подпись. Отключённые пункты пропускаются при пользовательском
выборе. Режим чтения сохраняет просмотр и навигацию, запрещая изменение выбора.

Доступность сохраняет иерархию списка: строки имеют `ListItem`, выбранность,
положение и общее число элементов, включая виртуализованные. Флажки дополнительно
публикуют checked и внутреннее действие `SemanticAction::Toggle`;
радиопредставление использует одиночный выбор без этого действия.
Клавиатурный фокус следует за текущей материализованной строкой.

В Windows отмеченность этого списка совпадает с выбранностью. Нативная проекция
использует `SelectionItemPattern`: `AddToSelection`, `RemoveFromSelection` и
`IsSelected`. Отдельный `TogglePattern` не публикуется. Это соответствует
[контракту ListItem](https://learn.microsoft.com/en-us/windows/win32/winauto/uiauto-supportlistitemcontroltype):
Toggle требуется для отметки, которая не меняет выбор. Текущий backend
обрабатывает `Select` как добавление элемента; исключительное снятие остальных
отметок через этот native метод не поддерживается. Программный
`set_selected_keys` задаёт полный набор выбора явно.

## Шаблон строки

`ListItemTemplate` — декларативное представление без интерактивных потомков.
`ListTemplateNode` содержит `LayoutStyle` и один из вариантов `ListTemplateKind`:

- `Stack` с направлением и дочерними узлами;
- `Text` с `TextStyle` и источником `Text`, `Key`, `Column(index)` либо `Literal`;
- `Icon` с собственным символом и `IconStyle`;
- `Separator` с настройками разделителя.

Отсутствующая колонка даёт пустой текст. Подпись для доступности берётся из
`SelectionItem.text` и его колонок независимо от декоративного шаблона.

```rust,ignore
ui.set_list_item_presentation(list.container, ListItemPresentation::CheckBox)?;
ui.set_list_item_template(list.container, Some(ListItemTemplate {
    root: ListTemplateNode {
        layout: LayoutStyle::default(),
        kind: ListTemplateKind::Text {
            source: ListItemTextSource::Text,
            style: TextStyle { wrap: true, ..Default::default() },
        },
    },
}))?;
```

Вызов с `None` восстанавливает обычную подпись. `list_item_content(list, key)`
возвращает текущий корень представления только для материализованной строки.
Для существующего ключа обновление данных меняет текст внутри прежних WidgetId.
Выход строки из окна виртуализации удаляет её поддерево; повторная материализация
создаёт новые WidgetId. Содержимое одного ключа не передаётся другому.

Один шаблон ограничен 32 узлами и 8 уровнями. Литерал ограничен 4096 байтами UTF-8,
размеры и отступы — 4096 логическими пикселями, процентные размеры — 100%.
Действуют общие ограничения текстового движка. Материализованные шаблоны используют
общий бюджет не более 4096 представлений кнопок на экземпляр `Controls`.
Команды, редакторы, отдельный фокус и обработчики ввода внутри шаблона не поддерживаются.
Недопустимый шаблон или данные отклоняются до замены текущего представления.

## Высота и виртуализация

`set_list_virtualization` задаёт оценочную высоту, запас строк и предел
материализации. `set_list_item_height(list, key, Some(height))` задаёт измеренную
высоту ключа, `None` возвращает оценочную. Явная высота остаётся определяющей:
перенос текста внутри шаблона не меняет её автоматически. Приложение задаёт
достаточную высоту, чтобы показать всё содержимое строки.

Геометрия использует стабильный ключ и смещение верхней строки при изменениях
коллекции и измерений. Прокрутка, hit testing и клавиатурное перелистывание
используют одну геометрию. Ошибка настроек, высоты, шаблона или лимита материализации
сохраняет прежние ключи, курсор, якорь и существующие представления.

Подробнее: [виртуализация](virtualization.md), [привязки форм](forms.md),
[наблюдаемые коллекции](observable-collections.md).

## Compiled XAML

```xml
<Window.Resources>
  <DataTemplate x:Key="PersonRow">
    <StackPanel Orientation="Horizontal" Spacing="8">
      <Icon Symbol="Copy" Width="16" Height="16" />
      <TextBlock Text="{Binding Text}" FontWeight="600" />
      <TextBlock Text="{Binding Column0}" />
    </StackPanel>
  </DataTemplate>
</Window.Resources>
<ListBox ItemsSource="{Binding People}" SelectionMode="Multiple"
         ItemPresentation="CheckBox" SelectedValues="{Binding SelectedPeople}"
         ItemTemplate="{StaticResource PersonRow}" />
```

`ItemPresentation` принимает `Plain`, `CheckBox` и `RadioButton`. Флажки требуют
`Multiple`, радиокнопки — `Single`. В `ComboBox` и `LookupEdit` представление строк
определяется режимом выбора; отдельно задавать `ItemPresentation` для них нельзя.

`ItemTemplate` ссылается на `DataTemplate` из текущего scope ресурсов. Допустима
также форма `<ListBox.ItemTemplate>…</ListBox.ItemTemplate>` с одним визуальным
корнем. Поддерживаются прозрачный `StackPanel`, `TextBlock`, `Icon`, `Separator`,
их размер, отступы, выравнивание и свойства текста. Бюджеты совпадают с Rust API.
Шаблон не принимает `x:Name`, `DataContext`, внешние ElementName bindings,
интерактивные элементы, команды или произвольные выражения.

Привязка `Text` внутри шаблона читает только текущий пункт: `Text`, `Key` либо
`Column0`…`Column31`. `ColumnN` — индекс дополнительной колонки `SelectionItem.columns`,
основная подпись доступна как `Text`. Отсутствующая колонка даёт пустой текст;
при текущем пределе 31 дополнительной колонки `Column31` всегда пуст.
Допустимы только OneWay/OneTime без конвертеров и fallback. Эти привязки не
участвуют в модели или namescope окна, а переиспользуемый шаблон получает данные
своего ключа при каждой материализации.
