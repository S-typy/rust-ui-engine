# GridControl для больших таблиц и вывода документов

Запустите `cargo run --release -p xaml-form -- --grid-workspace`. Раскройте «Запись, условия и связанные позиции». На вкладке «Оформление» можно ввести условие, изменить порядок правил и увидеть результат в таблице. На вкладке «Раскладка и вывод» доступны сохранение вида, предпросмотр, печать и экспорт. Вкладка «Страницы» открывает окно в источник с миллионом записей и 32 числовыми колонками.

## Правила и представление

```xml
<GridControl DataSource="Orders" WrapFields="Title" MergeFields="Category">
  <GridControl.FormatRules>
    <GridFormatRule FieldName="Paid" Kind="Expression" WholeRow="True"
                    Criteria='eq(field("Paid"),bool("false"))'/>
    <GridFormatRule FieldName="Quantity" Kind="DataBar"/>
    <GridFormatRule FieldName="Price" Kind="ColorScale"/>
  </GridControl.FormatRules>
  <GridControl.TextTemplates>
    <GridTextTemplate Target="Summary" Prefix="Итого · "/>
  </GridControl.TextTemplates>
</GridControl>
```

Правила применяются сверху вниз. У каждой ячейки выигрывает первое включённое совпадение. `WholeRow` распространяет результат условия на остальные поля записи. `Top` принимает положительный `Count`, при равенстве значений первым идёт меньший ключ. `AboveAverage` и `Duplicates` используют прошедшие фильтр записи. Пустая строка участвует в поиске дубликатов. NULL пропускается в статистических правилах. У полосы отрицательная часть расположена слева от нуля, положительная справа. Для равных значений шкала использует середину. `Icons` различает нижнюю, среднюю и верхнюю треть диапазона. `set_grid_format_rules` заменяет до 32 правил за одну операцию.

`GridTextTemplate` поддерживает цели `Header`, `Indicator`, `Summary` и аффиксы `Prefix`, `Suffix`. Для ячеек служит `GridCellTemplate`. Имя доступности учитывает подпись шаблона, значение ячейки остаётся доступным отдельно. В табличном виде `WrapFields` включает измерение перенесённого текста в реализованных строках. `MergeFields` визуально объединяет соседние одинаковые типизированные значения в колонке. Граница выделения и начало видимого фрагмента сохраняют подпись. Каждая запись сохраняет отдельный ключ для навигации и редактирования.

## Раскладки и контекст

`save_grid_layout(grid, name)` возвращает версионный JSON. `restore_grid_layout` проверяет имя, версию, поля, полосы, ширины и выражения перед применением. Файл сохраняет группировку, закрепление колонок, порядок, фильтры и правила. Новые колонки появляются в конце в своём исходном состоянии. Удалённое обязательное поле или повреждённый файл дают ошибку. В примере «Сохранить» и «Восстановить» явно работают с выбранным именем. В Windows каталог раскладок — `%LOCALAPPDATA%\rust-ui-engine\grid`.

`set_grid_context_menus` подключает команды приложения для заголовка, группы и записи. После активации команда получает поле или ключ через `grid_context_target`. Правый щелчок открывает меню цели, Shift+F10 открывает меню текущей строки, Ctrl+Shift+F10 — меню колонки. Alt+правый щелчок по заголовку открывает список значений фильтра. `auto_fit_grid_column` подбирает ширину по заголовку и показанным значениям в пределах MinWidth и MaxWidth. `set_grid_navigation_rows` принимает до восьми закреплённых записей и до 256 меток со стабильными ключами. Щелчок по метке или закреплённой записи переводит к ней. Поиск добавляет до 256 отметок совпадений.

Конструктор `rust_desktop_ui_xaml::design_grid_form` принимает зарегистрированное имя источника, схему и упорядоченный список полей. Перед возвратом разметка проходит компиляцию. Пример выводит список полей или готовую разметку в stdout.

```powershell
.\target\release\xaml-form.exe --grid-design --properties
.\target\release\xaml-form.exe --grid-design Code Title Price
```

## Страницы и группы провайдера

`GridPageView::mount` создаёт читаемую таблицу с источником `PagedDataSource`. `navigate` принимает смещение логической строки и возвращает запросы недостающих страниц. В форме смонтирована текущая страница. При переходе таблица освобождает прежние объекты представления. Фоновый исполнитель передаёт результат через `completion_sender`, затем `poll` принимает сообщения в потоке UI. Хост устанавливает `set_waker` и обслуживает запросы шапки через `take_input`. `status` различает ожидание, ошибку и готовые данные. `retry` выдаёт новый токен. Выбор хранится по ключу и восстанавливается при возвращении на страницу.

Операции сортировки и отбора входят в типизированный запрос провайдера. При изменении запроса поколение меняется, поздние ответы отбрасываются. `GridPageBranches` открывает до 16 независимых путей глубиной до восьми полей по группам, известным приложению. Загрузка начинается при раскрытии пути. `collapse` освобождает поддерево вместе с ожидающими запросами, пустой путь сворачивает всё. Настройки каждой страницы ограничивают количество строк, байтов и ожидающих ответов. Страница вывода и выделение относятся к конкретному экземпляру таблицы.

SQLite `query_page_with_totals` читает страницу, число совпадений и запрошенные итоги в одной транзакции. Для поддерживаемого отбора, порядка и итогов получается `Pushdown`. Поддерживаются порядковый поиск текстовой подстроки, количество строк и значений, целочисленные сумма, минимум и максимум. Для остальных поддержанных локальным движком выражений применяется ограниченный снимок. `accept_totals` связывает результат с поколением запроса и ревизией снимка. Возможности транспортного источника определяет его `QueryCapabilities`.

## Экспорт, предпросмотр и печать

`grid_output(grid, fields, selection_only)` создаёт неизменяемый снимок в порядке отфильтрованного представления. Пустой список полей означает текущие видимые колонки. Явный список задаёт поля и их порядок. При полном выводе раскрытие узлов на экране не ограничивает состав подходящих записей. При выводе выделения в документ попадают только выбранные записи, без общих итогов. Для отдельной детализации снимок строится по ID дочерней таблицы.

| Формат | Данные и границы |
|---|---|
| CSV | UTF-8, запятая, заголовок и строки записей. Кавычки удваиваются. Текст с запятыми и переводами строки заключён в кавычки. Отсутствующее значение и пустая строка записываются пустым полем. |
| XLSX | Типизированные числа, даты, время, флаги и строки. Применённый отбор определяет строки, заголовок получает AutoFilter, группы получают уровни outline до семи. Итоги записаны значениями. Целые и Decimal длиннее 15 значащих цифр сохраняются текстом для точности. Ограничение XML листа — 16 МиБ. |
| HTML | Таблица UTF-8 с заголовками и экранированным текстом. |
| RTF | Таблица с границами колонок, переносами, табуляцией и Unicode. |
| XLS | Однолистовый поток BIFF4. Числа, флаги и метки с ASCII и русскими буквами. Даты и значения повышенной точности представлены текстом. До 16 384 строк, включая заголовок, и 255 байт на текстовую метку. Непредставимый символ даёт ошибку. |
| Предпросмотр, PDF, печать | Один `PrintDocument`. Широкая таблица разбивается по колонкам, длинная — по строкам. На каждой странице повторяются полосы и заголовки её колонок и печатается номер страницы. Формат бумаги, поля, высоту строки и диапазон задаёт `GridPrintOptions`. |

Снимок ограничен миллионом ячеек и 32 МиБ полезных данных. Пример принимает форматы бумаги A4, A4-L, A5 и Letter. Поля заданы в DIP. Диапазон задан с единицы, например `2-4`, пустое значение выбирает все страницы. Команда «Отменить печать» посылает запрос фоновому заданию. Обработчик проверяет отмену во время построения документа, подготовки глифов и передачи страниц. После передачи всего задания управление очередью переходит к драйверу. Печать в Windows передаёт выбранную бумагу и ориентацию драйверу, неподдерживаемый формат возвращает ошибку. Полученные страницы можно передать в `PageViewer::print_preview`, `printing::export_pdf` или после подготовки глифов — системному принтеру.

Для фоновой проверки пример умеет формировать файлы без открытия окна. Укажите новый каталог и необязательный фильтр. С фильтром PDF содержит все страницы, при полном экспорте демонстрационных 10 000 заказов PDF содержит первую страницу. Форматы данных охватывают выбранный набор целиком.

```powershell
.\target\release\xaml-form.exe --grid-export orders-sample DOC-0000
```

Для виртуального принтера можно передать новый выходной файл, бумагу и диапазон. Пример отправляет вторую страницу на A5.

```powershell
.\target\release\xaml-form.exe --grid-print-file "Microsoft Print to PDF" orders-page.pdf DOC-0000 A5 2
```
