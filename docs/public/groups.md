# Группы и раскрывающиеся секции

`GroupBox` объединяет содержимое под заголовком и при `IsCollapsible="True"`
допускает сворачивание. `Expander` всегда предоставляет раскрытие.
`TabbedGroup` размещает несколько постоянных страниц под вкладками.
Все эти элементы поддерживают вложенные
контейнеры, редакторы и привязки, а оформление следует текущей светлой или
тёмной теме.

Пример [GroupsWindow.xaml](../../examples/xaml-form/GroupsWindow.xaml):

```text
cargo run --release --locked -p xaml-form -- --groups
cargo run --release --locked -p xaml-form -- --groups --dark
```

## XAML

```xml
<GroupBox Header="Документ" Appearance="Card" Padding="16"
          DataContext="{Binding Document}">
  <StackPanel Spacing="12">
    <TextBox Text="{Binding Title}" />
    <Expander Header="Дополнительные параметры"
              IsExpanded="{Binding ShowDetails}" Appearance="Outline">
      <StackPanel Spacing="8">
        <DateEdit Value="{Binding Date}" />
        <TextBox Text="{Binding Note}" />
      </StackPanel>
    </Expander>
  </StackPanel>
</GroupBox>
```

| Свойство | Контракт |
|---|---|
| `Header` | Текст заголовка, не более 4096 байт UTF-8; пустая строка разрешена |
| `Appearance` | `Card` по умолчанию, `Outline`, `Plain` или `Standard` |
| `HeaderStyle` | `Normal` по умолчанию, `Light` или `Accent` |
| `HeaderIcon` | Необязательный символ из общего набора Icon |
| `ShowHeader` | По умолчанию `True`; `False` удаляет строку заголовка из компоновки статической группы |
| `CornerRadius` | По умолчанию из темы; явное значение от 0 до 16384 |
| `HeaderForeground`, `HeaderBackground` | Необязательные цвета `#RRGGBB` или `#AARRGGBB`, с сохранением прозрачности |
| `Padding` | Отступ содержимого; по умолчанию 16 логических пикселей со всех сторон |
| `IsCollapsible` | Только GroupBox; по умолчанию `False` |
| `IsExpanded` | Expander и сворачиваемый GroupBox; по умолчанию `True` |

`Card` использует отдельную поверхность с рамкой и скруглением; `Outline` —
контурную группу; `Plain` — заголовок без внешней рамки. `Standard` рисует
классическую рамку с прозрачным разрывом под подписью. Подпись не закрашивает
предполагаемый фон родителя, поэтому вложенные поверхности остаются видны.
Цвета выбираются из текущей темы. Смена темы не пересоздаёт содержимое.

`HeaderStyle` независим от рамки. `Normal` использует полосу высотой 48,
`Light` — компактный заголовок высотой 36 с облегчённым начертанием,
`Accent` — полосу высотой 48 с акцентом текущей темы. Все размеры логические.
Явные цвета заголовка сохраняются при смене темы; незаданные следуют теме.
В недоступной группе текст и значок получают недоступное состояние.

Скрывать заголовок Expander или сворачиваемого GroupBox запрещено: это убрало бы
средство раскрытия. `IsExpanded=False` и привязка `IsExpanded` у статического
GroupBox отклоняются. Иконка декоративная, доступное имя задаётся Header либо
AutomationName. Произвольные контролы внутри заголовка этим API не задаются.

Внутри допускается один элемент или пустое содержимое. Для нескольких полей
используйте StackPanel, Grid либо другой контейнер. Общие свойства размеров,
выравнивания, Grid-размещения, `Visibility`, `IsEnabled`, `AutomationName`
и `DataContext` работают как у остальных элементов формы.

`Header` допускает привязку с направлением `OneWay` по умолчанию.
`IsExpanded` использует `TwoWay` / `PropertyChanged`: изменение модели раскрывает
секцию, а действие пользователя обновляет модель. Оба свойства доступны через
`ElementName`. Контекст данных наследуется содержимым группы; группа сама по
себе не создаёт отдельного пространства XAML-имён.

## Поведение

Статический GroupBox не создаёт дополнительную остановку Tab. Заголовок Expander
доступен с клавиатуры: Enter или Space переключает раскрытие. Состояние и
действия раскрытия передаются в дерево доступности.

Сворачивание исключает содержимое из компоновки и взаимодействия, сохраняя
его WidgetId, документы, выбор и привязки. Это не удаление и не повторный
монтаж. Состояние вложенного Expander также сохраняется. При автоматической
высоте секция сжимается до заголовка; явно заданная внешняя высота сохраняется.
Корневой статический GroupBox с автоматической высотой и `VerticalAlignment="Stretch"`
заполняет доступную высоту формы. Корневой Expander сохраняет автоматическое
измерение, чтобы свёрнутая секция занимала только высоту заголовка. Это же
правило действует для корневого GroupBox с `IsCollapsible="True"`.

Привязки продолжают получать изменения модели, когда секция свёрнута.
Клик по заголовку проходит обычную смену фокуса и применяет
`CommitOnLostFocus` редактора. Программное сворачивание сохраняет обычный
черновик без автоматического подтверждения и отменяет незавершённый IME preedit.
Если фокус находился в содержимом, он переводится на доступный заголовок.
Сворачивание не добавляет отдельной транзакции подтверждения всей группы.

## Rust API

`Controls::group_box` принимает `GroupSettings` и `LayoutStyle`, возвращая
`GroupBox` с идентификаторами `container`, `header` и `content`.
`Controls::expander` дополнительно принимает начальное состояние раскрытия
и возвращает такие же части в `Expander`. Дочерние контролы создаются в `content`.

`GroupSettings` задаёт `header`, `appearance: GroupAppearance`, `padding`,
`header_style: GroupHeaderStyle`, `header_icon`, `show_header`, `corner_radius`
и необязательные `header_foreground` / `header_background`.
Для сворачиваемого GroupBox используется `Controls::collapsible_group_box`.
Заголовок меняется через `set_group_header`, настройки — через
`set_group_settings`. `expander_expanded` читает состояние, а
`set_expander_expanded` меняет его. Все эти операции используют идентификатор
контейнера. Привязки представлены `BindingProperty::Header` и
`BindingProperty::IsExpanded`.

Для удаления всей группы используйте `container`. Удаление обязательного
служебного заголовка или контейнера содержимого отдельно отклоняется до
изменения дерева; обычные пользовательские дети удаляются независимо.

## Группа со вкладками

```xml
<TabbedGroup SelectedIndex="{Binding ActivePage}" Padding="16">
  <GroupTab Header="Основное" HeaderIcon="Edit">
    <TextBox Text="{Binding Title}" />
  </GroupTab>
  <GroupTab Header="Дополнительно" HeaderIcon="Copy">
    <TextBox Text="{Binding Note}" />
  </GroupTab>
  <GroupTab Header="Доступ" IsEnabled="False" />
</TabbedGroup>
```

TabbedGroup содержит от 1 до 64 GroupTab. У каждой вкладки непустой Header
до 4096 байт UTF-8, необязательный HeaderIcon и IsEnabled=True по умолчанию.
Вкладка содержит не более одного элемента; пустая страница допустима.
GroupTab задаёт метаданные страницы, а общие свойства формы, x:Name и
DataContext задаются TabbedGroup либо элементу содержимого.

SelectedIndex — целый индекс от нуля; начальное значение 0. При создании и
изменении выбора целевая вкладка должна существовать и быть доступной. Привязка использует
TwoWay/PropertyChanged по умолчанию, допускает ElementName и числовой FallbackValue.
Неактивные страницы продолжают получать изменения модели.

Стрелки Left/Right и Home/End выбирают доступную вкладку; в Tab-порядке
участвует выбранный заголовок. Если он позднее отключён через Rust API,
страница сохраняется, а остановка Tab переходит на первый доступный заголовок;
автоматической смены SelectedIndex нет. Доступность содержит роли TabList/Tab и
selected state. Неактивные страницы исключены из компоновки и дерева
доступности, но их редакторы, WidgetId, выделение и undo остаются живыми.
Программная смена страницы не подтверждает draft и отменяет IME preedit.
Клик по вкладке проходит обычный CommitOnLostFocus. Всплывающие окна скрываемой
страницы закрываются; внутренний фокус переходит на выбранный заголовок.

Rust: `Controls::tabbed_group(parent, Vec<GroupTab>, selected_index, style)`
возвращает `TabbedGroup { container, headers, contents }`. `GroupTab` содержит
`header`, `icon`, `enabled`. Используются `selected_tab`, `set_selected_tab`
и `BindingProperty::SelectedIndex`. Существующий TabControl использует ту же
модель. Обязательные части удаляются только вместе с владельцем.

Профиль поддерживает текстовые заголовки со значками и вертикальное раскрытие вниз.
Произвольные HeaderTemplate, анимации раскрытия, accordion-взаимоисключение
и генерация полей по модели не входят в этот контракт.
